# WG Console 1 Preset Bridge

Bring your DAW plug-in presets into **Softube Console 1** channel strips.

Console 1 runs plug-ins without their own windows or preset browsers, so the presets you've saved in your DAW can't be loaded there. This app copies a preset's settings into a Console 1 strip (`.spt`) that you load from the Console 1 browser.

**Download:** grab `WG-Console-1-Preset-Bridge-Setup-*.exe` from the [latest release](https://github.com/woodgrain816/WG-Console-1-Preset-Bridge-releases/releases/latest). Windows, no admin needed.
